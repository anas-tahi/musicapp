## ✨ Features

- 🎵 Upload and stream music tracks
- 👤 User profiles and follow system
- ❤️ Like and save songs to your library
- 🔍 Search artists and tracks
- 📱 Runs on iOS & Android via Expo

## 🛠️ Tech Stack

| Layer | Tech |
|---|---|
| Mobile Frontend | React Native + Expo |
| Backend | Node.js + Express |
| Database | MongoDB |
| Auth | JWT |
| File Storage | Multer |

## 🚀 Run Locally

```bash
git clone https://github.com/anas-tahi/musicapp
cd musicapp

# Backend
cd backend && npm install && npm start

# Mobile app
cd frontend && npm install && npx expo start
```
